# Open-Field Behavioral Analysis Using DeepLabCut

This project demonstrates a DeepLabCut-based workflow for quantitative behavioral analysis in rodent open-field experiments.

Using pose-estimation outputs, the pipeline extracts locomotion trajectories, movement velocity, spatial occupancy heatmaps, and distance-traveled metrics from tracked body-part coordinates.

The project was developed as part of self-training in computational behavioral neuroscience and reproducible behavioral analysis workflows.


The workflow includes:
- Pose extraction from video
- Trajectory visualization
- Distance traveled analysis
- Velocity estimation
- Spatial occupancy heatmap generation

The project was implemented using Python, DeepLabCut, NumPy, pandas, and Matplotlib.
